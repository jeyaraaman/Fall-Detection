 Abstract - Falls are a major health risk for elderly individuals and patients with mobility issues. Rapid detection of falls can significantly reduce injury severity and improve emergency response time. This paper proposes a realtime fall detection system using inertial sensor data collected from an accelerometer and gyroscope. Motion signals are processed using a hybrid deep learning model combining Convolutional Neural Networks (CNN) and Gated Recurrent Units (GRU). The model is trained using the SisFall dataset and validated using the MobiFall dataset. The trained model is deployed on a Raspberry Pi 5 for realtime inference using IMU sensor inputs. Experimental results demonstrate that the proposed system can effectively distinguish fall events from normal activities while maintaining low computational requirements suitable for edge devices.
I. Introduction
Falls represent a major health concern, particularly among elderly individuals and patients suffering from neurological disorders or mobility limitations. According to global healthcare statistics, falls are one of the primary causes of injury-related hospitalization among older adults. When a fall occurs without immediate assistance, it may lead to severe medical complications such as fractures, internal injuries, or prolonged immobilization.
Traditional monitoring systems rely on manual observation or emergency call devices, which may not always be effective when the individual is unconscious or unable to request help. With advancements in wearable sensors and machine learning technologies, automated fall detection systems have emerged as a promising solution for improving elderly care and patient safety.
In recent years, inertial sensors such as accelerometers and gyroscopes have been widely used for activity recognition and motion analysis. These sensors are capable of capturing sudden changes in body movement that typically occur during fall events.This research proposes a fall detection system using an Inertial Measurement Unit (IMU) consisting of accelerometer and gyroscope sensors. The motion signals are analyzed 
using a hybrid deep learning architecture combining Convolutional Neural Networks (CNN) and Gated Recurrent Units (GRU). The trained model is deployed on a Raspberry Pi 5 device to perform real-time fall detection at the edge.
II. System Overview
The proposed fall detection system monitors body motion continuously using an IMU sensor that contains both an accelerometer and gyroscope. These sensors measure linear acceleration and angular velocity along multiple axes, enabling accurate motion analysis.
The sensor data is collected and processed by Raspberry Pi 5, which acts as the central processing unit of the system. The device runs a pre-trained deep learning model capable of distinguishing fall events from normal daily activities.
The system workflow consists of several stages including sensor data acquisition, signal preprocessing, feature extraction, deep learning-based classification, and fall detection output. When the system identifies abnormal motion patterns indicating a fall, it can trigger alerts to notify caregivers or healthcare providers.
The primary goal of the system is to provide a portable, real-time, and cost-effective fall detection solution for elderly individuals living independently.
III. Hardware Components
The fall detection system utilizes several hardware components to capture motion data and perform real-time analysis.
Raspberry Pi 5:
Raspberry Pi 5 serves as the main processing unit of the system. It collects sensor readings, processes motion data, and executes the trained deep learning model. The device is selected for its high processing capability, compact size, and ability to run machine learning frameworks.
IMU Sensor (Accelerometer and Gyroscope):
An IMU sensor such as MPU6050 is used to capture body movement data. The sensor provides six-axis motion information including:
Three-axis acceleration
Three-axis angular velocity
These measurements help detect sudden impacts and abnormal movements that occur during fall events.
Power Supply:
A portable battery source is used to power the Raspberry Pi and sensors, enabling the system to operate as a wearable device.
IV. Circuit Design
The hardware circuit consists of Raspberry Pi 5 connected to an IMU sensor through an I2C communication interface. The accelerometer and gyroscope readings are continuously transmitted to the Raspberry Pi.
The Raspberry Pi processes the incoming sensor signals and feeds them into the trained CNN-GRU model for fall detection. The entire circuit is compact and designed to be integrated into a wearable device.

V. Working Description
The proposed fall detection system operates through the integration of motion sensing, signal processing, and deep learning-based classification. The system continuously monitors the user's body movements using an Inertial Measurement Unit (IMU) consisting of an accelerometer and gyroscope. These sensors capture real-time motion data which is processed by Raspberry Pi 5 to determine whether a fall has occurred.
Sensor Data Acquisition:
The first stage of the system involves collecting motion signals from the IMU sensor. The accelerometer measures linear acceleration along three axes (X, Y, and Z), while the gyroscope measures angular velocity across the same axes. These measurements represent the movement and orientation of the human body during various activities.
During normal daily activities such as walking, sitting, or standing, the acceleration and angular velocity values change gradually within a specific range. However, during a fall event, there is a sudden spike in acceleration followed by an abrupt change in body orientation. These abnormal patterns are captured by the IMU sensor and transmitted to the Raspberry Pi through the I2C communication interface.
The sensor continuously samples motion data at a fixed frequency, generating a stream of real-time movement information.
Data Preprocessing:
Raw sensor signals often contain noise and irregular variations that may affect the performance of the machine learning model. Therefore, preprocessing techniques are applied before feeding the data into the deep learning network.
The preprocessing stage includes:
Filtering unwanted noise from sensor readings
Normalizing acceleration and gyroscope values
Segmenting continuous data into fixed-size time windows
Converting sensor values into structured sequences suitable for model input
Each data window represents a short time interval of motion signals, which helps the model analyze the sequence of movements leading to a potential fall event.
Feature Extraction Using CNN:
After preprocessing, the segmented motion sequences are provided as input to the Convolutional Neural Network (CNN) layers. The CNN is responsible for extracting spatial features from the sensor signals.
Convolutional layers apply multiple filters across the input data to detect meaningful patterns such as sudden impacts, rapid body movement, or abnormal acceleration peaks. These patterns are essential indicators of fall events.
Through repeated convolution and pooling operations, the CNN compresses the raw sensor data into a set of high-level feature representations. These extracted features summarize the important motion characteristics present in the input signals.
Temporal Analysis Using GRU:
Human motion is inherently sequential in nature, meaning that understanding how movement evolves over time is critical for accurate fall detection. Therefore, the extracted features from the CNN layers are passed to the Gated Recurrent Unit (GRU) network.
GRU is a type of recurrent neural network that is designed to process sequential data efficiently. It maintains memory of previous time steps and analyzes temporal dependencies within the motion sequence.
The GRU layers examine how body movement changes over time and determine whether the sequence represents a normal activity or a fall event. This temporal modeling helps reduce false detections caused by sudden but harmless movements such as sitting quickly or jumping.
Fall Classification:
The final stage of the system involves classification of the motion sequence. The output layer of the neural network produces a probability value between 0 and 1 representing the likelihood of a fall.
If the predicted probability exceeds a predefined threshold, the system classifies the event as a fall. Otherwise, the activity is categorized as a normal daily movement.
For example:
Probability close to 0 indicates normal activity.
Probability close to 1 indicates a fall event.
Real-Time Inference on Raspberry Pi 5:
Once the CNN-GRU model is trained using the dataset, the trained model is deployed on Raspberry Pi 5 for real-time operation. The Raspberry Pi continuously reads sensor data from the IMU and performs inference using the trained model.
The device processes incoming motion sequences in real time and predicts whether the current movement pattern corresponds to a fall event. This edge-based processing eliminates the need for cloud computation and ensures low-latency detection.
System Response:
When the system detects a fall event, it can trigger an alert mechanism such as a notification, alarm, or emergency message to caregivers or family members. This rapid detection and alerting mechanism significantly improves response time and enhances the safety of elderly individuals living independently.
The complete monitoring process runs continuously after system initialization. Upon powering on, the Raspberry Pi initializes the sensor interface, loads the trained deep learning model, and begins monitoring motion data in real time.

VI. Dataset Used
SisFall Dataset:
The SisFall dataset is widely used in fall detection research. It contains motion data collected from wearable sensors during various fall scenarios and daily activities.The dataset includes recordings of multiple subjects performing both normal activities and simulated falls. The accelerometer and gyroscope signals provide valuable information for training machine learning models.
MobiFall Dataset:
The MobiFall dataset is used to evaluate the performance of the trained model under real-world conditions. It contains motion data recorded from smartphone sensors during human activities and fall events.Using both datasets improves the generalization ability of the proposed model.
VII. Machine Learning Model
The proposed fall detection system utilizes a hybrid deep learning architecture that combines Convolutional Neural Networks (CNN) and Gated Recurrent Units (GRU). This hybrid model is designed to capture both spatial and temporal features from motion signals obtained through inertial sensors. The integration of CNN and GRU allows the system to effectively recognize complex motion patterns associated with fall events.
Human motion data collected from accelerometer and gyroscope sensors consists of sequential time-series signals. These signals contain both spatial characteristics (such as sudden acceleration spikes) and temporal dependencies (how the movement evolves over time). The CNN-GRU architecture is capable of extracting these features efficiently, making it suitable for fall detection tasks.
A. Input Data Representation:
The input to the machine learning model consists of time-series motion data obtained from the IMU sensor. Each sample includes measurements from:
Accelerometer X-axis
Accelerometer Y-axis
Accelerometer Z-axis
Gyroscope X-axis
Gyroscope Y-axis
Gyroscope Z-axis
These six sensor channels form a multivariate time-series signal. The continuous data stream is divided into fixed-size time windows before being fed into the neural network.
Each time window represents a short duration of human movement and contains multiple sensor readings. This segmentation allows the model to analyze the sequence of movements leading up to a potential fall event.
B. Convolutional Neural Network (CNN):
The first component of the hybrid architecture is the Convolutional Neural Network. CNN layers are responsible for extracting spatial features from the input sensor signals.
Convolutional filters slide across the time-series data and identify patterns such as:
Sudden spikes in acceleration
Rapid changes in angular velocity
Impact signals during a fall
Sudden body orientation shifts
These filters automatically learn important motion features during the training process. The CNN layers transform raw sensor signals into high-level feature maps that represent meaningful movement patterns.
Pooling layers are applied after convolution operations to reduce the dimensionality of the feature maps. This helps improve computational efficiency and prevents overfitting by retaining only the most significant features.
The CNN module therefore acts as a feature extractor that converts raw motion signals into compact representations suitable for sequential analysis.
C. Gated Recurrent Unit (GRU)
After spatial feature extraction by CNN layers, the feature sequences are passed to the Gated Recurrent Unit (GRU) network. GRU is a type of recurrent neural network designed for processing sequential data.
Human motion is inherently temporal, meaning that the order of movements is important for recognizing activities. GRU networks analyze the relationship between consecutive time steps in the motion sequence.
The GRU unit contains two primary gates:
1. Update Gate:This gate determines how much information from the previous hidden state should be carried forward to the current state.
2. Reset Gate:This gate controls how much of the previous information should be ignored while processing new input data.These gating mechanisms allow the GRU network to maintain relevant motion information while discarding unnecessary data. As a result, the model can effectively learn temporal patterns associated with fall events.
GRU networks are preferred in this system because they require fewer parameters compared to traditional Long Short-Term Memory (LSTM) networks, making them more suitable for deployment on embedded devices such as Raspberry Pi.
D. Fully Connected Layer:
The output generated by the GRU layer is passed to a fully connected dense layer. This layer combines the extracted spatial and temporal features and performs the final classification.
The dense layer applies a nonlinear transformation to the input features and prepares them for binary classification.
E. Output Layer:
The final output layer uses a sigmoid activation function to produce a probability value between 0 and 1.
The output represents the likelihood of a fall event occurring within the analyzed motion window.
Output close to 0 → Normal activity
Output close to 1 → Fall detected
A threshold value is defined to classify the activity as either a fall or a normal movement.
F. Model Training:
The CNN-GRU model is trained using labeled motion data from the SisFall dataset. The training process involves feeding the segmented sensor sequences into the neural network and adjusting model parameters through backpropagation.
The model learns to distinguish between fall events and normal daily activities by minimizing the loss function during training.
Training is performed for multiple epochs until the model achieves satisfactory performance on the validation dataset.
G. Model Deployment:
Once the model is trained, the final trained model is exported and deployed on the Raspberry Pi 5 device. The Raspberry Pi loads the trained model and performs real-time inference on incoming sensor data.The device processes each motion sequence and predicts whether a fall event has occurred. This edge-based inference allows the system to operate without requiring constant internet connectivity.
The lightweight CNN-GRU architecture ensures efficient execution on embedded hardware while maintaining high detection accuracy.
VIII. Model Training and Evaluation
The proposed CNN-GRU model was trained using motion data obtained from the SisFall dataset, which contains multiple recordings of human activities and fall events captured through inertial sensors. The dataset includes both Activities of Daily Living (ADL) and fall scenarios, allowing the model to learn the difference between normal movements and dangerous fall events.
The entire dataset was preprocessed and divided into training and validation subsets before the model training process.
A. Training Process:
During training, the motion signals obtained from accelerometer and gyroscope sensors were segmented into fixed-length time windows. Each window contains sequential sensor readings representing a short duration of human movement.
These segmented sequences were used as input samples for the CNN-GRU model. The model learns to identify motion patterns associated with falls and normal daily activities through multiple training iterations known as epochs.
The training process was performed for 20 epochs, allowing the neural network to gradually optimize its internal parameters and improve classification performance.
During each epoch, the following steps occur:
Input sensor sequences are fed into the CNN layers.
CNN extracts spatial motion features.
GRU processes temporal relationships between sequential signals.
The final layer predicts whether the activity corresponds to a fall or a normal activity.
The predicted output is compared with the true label.
The error is calculated using the loss function.
Model weights are updated using backpropagation.
This process continues until the model achieves stable performance.
B. Loss Function:
The training process uses Binary Cross-Entropy Loss as the loss function since fall detection is a binary classification problem.

X. Conclusion
This paper presented a real-time fall detection system using accelerometer and gyroscope sensors combined with a CNN-GRU deep learning model. The system is implemented on Raspberry Pi 5 for edge-based processing and real-time inference.
The experimental results demonstrate that the proposed system can effectively detect fall events while maintaining low computational requirements. The system has the potential to improve safety and emergency response for elderly individuals and patients requiring continuous monitoring.
Future improvements may include integration of additional sensors, mobile alert systems, and cloud-based monitoring platforms.
